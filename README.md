Bem-vindo ao FrequenIA, aplicativo para gerenciamento de pontos eletrônicos utilizando reconhecimento facial. 







# Guia de Estilo FrequenIA (Versão Atualizada)
Este documento define os padrões visuais oficiais para o sistema FrequenIA.
---

## 1. Paleta de Cores

- **FrequenIA Blue**  
  Variável: `--color-primary`  
  Cor: `#0f5c8c`  
  Uso: Botões principais, ícones, textos de destaque  

- **Dark Blue**  
  Variável: `--color-primary-dark`  
  Cor: `#0c4a70`  
  Uso: Hover de botões e elementos interativos  

- **White**  
  Variável: `--color-white`  
  Cor: `#ffffff`  
  Uso: Fundos de cards, texto em botões  

- **Light Gray**  
  Variável: `--color-bg-light`  
  Cor: `#f0f2f5`  
  Uso: Fundo da página  

- **Medium Gray**  
  Variável: `--color-border`  
  Cor: `#e5e7eb`  
  Uso: Bordas, divisores e tabelas  

- **Dark Gray**  
  Variável: `--color-text-dark`  
  Cor: `#222222`  
  Uso: Títulos e textos principais  

- **Input BG**  
  Variável: `--color-input-bg`  
  Cor: `#fafbfc`  
  Uso: Fundo de inputs  

---

## 2. Tipografia 

Fonte principal: **Montserrat**

- **Título de Página**  
  `28px` | Peso `700` | Cor `--color-text-dark`

- **Título de Seção**  
  `20px` | Peso `600` | Cor `--color-text-dark`

- **Subtítulo / Card Title**  
  `18px` | Peso `600` | Cor `#111`

- **Label de Campo**  
  `18px` | Peso `600` | Cor `--color-text-light` | `uppercase`

- **Texto de Corpo**  
  `18px` | Peso `400` | Cor `--color-text-dark`

- **Texto de Destaque**  
  `18px` | Peso `700` | Cor `--color-primary`

- **Table Header**  
  `18px` | Peso `600` | Cor `--color-text-light` | `uppercase`

- **Badges**  
  `18px` | Peso `600` | Cor `--color-primary-dark`

---

## 3. Componentes

### Cards
- Padding: `22px 24px`
- Border Radius: `10px`
- Shadow: `0 2px 10px rgba(0, 0, 0, 0.07)`

### Botões
- Height: `40px`
- Font Size: `18px`
- Border Radius: `7px`
- Weight: `600`

### Inputs e Selects
- Height: `40px`
- Font Size: `18px`
- Border: `1.5px solid #dde1e7`
- Background: `#fafbfc`

### Tabelas
- Font Size: `18px`
- Header Padding: `10px 14px`
- Cell Padding: `13px 14px`
- Hover: `#fafbfc`
